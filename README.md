# Fiber Connect Hub

# Fiber Tech Website - Product Requirements Document (PRD)

## Project Overview

Create a premium, modern, responsive, SEO-optimized corporate website for **Fiber Tech**, a Brazilian Internet Service Provider (ISP).

This website must represent a premium technology company, focusing on trust, speed, innovation and conversion.

The final design should feel comparable to websites from companies like Apple, Starlink, Google Fiber and Cloudflare.

The generated project will be embedded into an existing **WordPress website**, therefore it must be compatible with WordPress without requiring its own CMS.

---

# IMPORTANT LANGUAGE REQUIREMENT

All instructions in this document are written in English.

However:

**Every visible text shown to visitors MUST be written in Brazilian Portuguese (pt-BR).**

This includes:

- Navigation
- Buttons
- Forms
- Titles
- Paragraphs
- Plans
- Notifications
- Labels
- Footer
- FAQ
- Contact information

Never display English text inside the website.

---

# WORDPRESS COMPATIBILITY

This project will be embedded into an existing WordPress website.

Requirements:

• Compatible with WordPress

• Compatible with Elementor

• Compatible with Gutenberg

• Do not create a CMS

• Do not create authentication

• Do not create admin dashboard

• Avoid global CSS conflicts

• Isolate styles whenever possible

• Frontend only

• Easy future integration
